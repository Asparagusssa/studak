# Студак — бот MAX

В этой папке лежит исходный Python-проект «Искра». Для Studak рабочий обработчик MAX уже находится в [Go-бэкенде](../../backend/internal/bots/maxbot). Он принимает `POST /webhook/max` и использует общий PostgreSQL, анкеты, фильтры вузов и лайки Studak. Python и его отдельную SQLite для такого запуска поднимать не нужно.

## Локальный запуск Studak

1. Создай `backend/.env` из `backend/.env.example`, если его нет. Заполни `POSTGRES_PASSWORD`, `API_TOKEN`, `MAX_BOT_TOKEN` и случайный `MAX_WEBHOOK_SECRET` (например, `openssl rand -hex 32`). Переменные читаются на сервере.
2. Из корня репозитория запусти `./frontend/max-bot/start.sh --ngrok`. Нужны Docker, ngrok, Python 3 и curl; ngrok должен быть авторизован через `ngrok config add-authtoken <токен-ngrok>`. Скрипт создаёт HTTPS-туннель, поднимает Go-бэкенд, PostgreSQL и миграции, передаёт адрес в `WEBHOOK_BASE_URL`. Адрес в `.env` менять не нужно. Для Cloudflare Quick Tunnel используй `--dev-tunnel`, для запуска только локального API — команду без аргументов.
3. Проверь `docker compose -f backend/docker-compose.yml --env-file backend/.env logs --tail=50 backend`: после регистрации появится `webhooks: max -> https://…/webhook/max`. Отправь боту `/start` в MAX.

Локальный API доступен по `http://127.0.0.1:8080` (порт можно поменять в `backend/.env`). В режиме ngrok оставь терминал открытым; Ctrl+C остановит только туннель. После изменения токенов в `.env` запусти команду заново. В режиме Cloudflare туннель работает в контейнере; остановка: `docker stop studak-max-dev-tunnel`. Данные Studak сохраняются в томе PostgreSQL.

## Кого искать

При регистрации бот отдельно спрашивает, кого показывать в ленте: девушек, парней или всех. В готовой анкете это можно изменить кнопкой «Кого искать» в меню. Фильтр по вузам продолжает действовать. Для существующих анкет начальное значение — «Всех».

## Фото в анкете MAX

В конце регистрации нужно отправить одно изображение из галереи MAX. Без фото анкета не публикуется. В готовой анкете меню «Моя анкета» → «Фото» позволяет добавить или заменить изображение; удалить обязательное фото нельзя. В ленте MAX фото показывается вместе с анкетой.

Для фото из MAX в PostgreSQL хранится токен вложения, а не временная ссылка. Он не возвращается в REST API. Поэтому такое фото отображается в MAX; загрузка для сайта через это меню не настраивается. Миграция Goose применяется при запуске через Docker Compose.

## Входящие лайки и сообщения

«Кто меня лайкнул» показывает новые симпатии по одной. Можно нажать «Ответить взаимностью» или «Пропустить». Мэтчи остаются в разделе «Мои мэтчи». После взаимного лайка бот показывает контакт и кнопку перехода в профиль. Контакт обязателен при регистрации в MAX: номер телефона, личная ссылка Telegram или MAX. Изменение доступно в «Моя анкета» → «Контакт для связи». API MAX не передаёт username обычного пользователя. Пересылка личных сообщений через бота отключена.

## Тестовые анкеты МГУ

Скрипт `backend/scripts/seed-demo-msu.sh` создаёт Web/API-анкеты без messenger ID.
После разделения мессенджеров они не показываются в Telegram и MAX. Для проверки
бота нужны отдельные тестовые аккаунты в соответствующем мессенджере с фото и,
для MAX, контактом. Старый режим `--with-likes` не используйте для тестирования
ботов: его связи с Web-фикстурами исключаются из выдачи.

## Видимость и блокировки

В главном меню кнопкой «⚙️ Настройки» можно поставить её на паузу, вернуть в поиск или удалить. Пауза скрывает анкету из поиска и откладывает новые лайки, а существующие мэтчи и контакты остаются доступны. При удалении бот просит подтвердить действие; уже отправленные в MAX сообщения остаются в мессенджере.

Кнопка «Ещё» на карточке, в мэтче и в полученном сообщении открывает блокировку. После неё анкеты скрываются в обе стороны и мэтч удаляется. Уже полученный контакт остаётся у собеседника. Снять блокировку можно в настройках; старый мэтч при этом не возвращается.

## Переезд на хостинг

1. Запусти Go-бэкенд с PostgreSQL и настрой публичный HTTPS для `/webhook/max`.
2. В секретах хостинга укажи `MAX_BOT_TOKEN`, новый случайный `MAX_WEBHOOK_SECRET` и `WEBHOOK_BASE_URL=https://постоянный-домен` (без `/webhook/max`). Перезапусти бэкенд и проверь ответ на `/start`.
3. Останови временный туннель и удали его подписку через [API MAX](https://dev.max.ru/docs-api/methods/DELETE/subscriptions). Go-бэкенд заменяет подписку только для точного URL.

## Python-демо без токена

Из этой папки запусти `python3 -m iskra demo`. Тесты: `python3 -m unittest discover -s tests -v`. Этот режим использует тестовые анкеты в памяти и не подключается к Studak или MAX. Не используй токен рабочего Go-бота для запуска Python-версии.

## Обновлённый поиск и карточки

В регистрации доступны «Парень» и «Девушка». В справочнике есть 66 организаций
и филиалов Удмуртии, включая колледжи и техникумы. Введи название, часть названия
или сокращение: небольшие опечатки допустимы, бот предложит близкие варианты.
На карточке ❤️ означает лайк, 👎 — пропуск на два часа. Кнопка «Заблокировать»
открывает подтверждение сразу с карточки.

Лента ограничена возрастом ±2 года. Примерно 2/3 показов отдаётся приоритету:
парням — девушки младше на 1–2 года, девушкам — парни старше на 1–2 года.
Остальные показы разбавляют ленту ровесниками и другими подходящими людьми
в пределах ±2 лет. Когда одна группа заканчивается, используется другая.
Подробные правила и источники справочника — в `backend/README.md`.

## Контакты

Контакт открывается после взаимного лайка, в том числе через «Мои мэтчи».
В Telegram это `@username` и кнопка перехода, а при отсутствии username —
ссылка на профиль, если её разрешают настройки Telegram. Username обновляется
при взаимодействии пользователя с ботом; для существующей анкеты отправь `/start`.
В MAX обязательный контакт запрашивается при регистрации: телефон, Telegram или MAX. Его можно изменить в «Моя анкета» → «Контакт для связи».
Старые кнопки «Написать» открывают контакт; введённый в бот текст собеседнику
не пересылается.

## Разделение мессенджеров

В Telegram видны только анкеты Telegram, в MAX — только анкеты MAX. Это относится
к ленте, входящим лайкам и мэтчам, включая старые кнопки и прежние связи.
В MAX контакт собирается на шаге 8/9, фото — на 9/9. Анкеты без контакта временно
скрыты из выдачи: отправь `/start`, чтобы дополнить существующую анкету.
