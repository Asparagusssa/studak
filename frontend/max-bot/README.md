# Искра — бот MAX

В этой папке лежит исходный Python-проект «Искра». Для Studak рабочий обработчик MAX уже находится в [Go-бэкенде](../../backend/internal/bots/maxbot). Он принимает `POST /webhook/max` и использует общий PostgreSQL, анкеты, фильтры вузов и лайки Studak. Python и его отдельную SQLite для такого запуска поднимать не нужно.

## Локальный запуск Studak

1. Создай `backend/.env` из `backend/.env.example`, если его нет. Заполни `POSTGRES_PASSWORD`, `API_TOKEN`, `MAX_BOT_TOKEN` и случайный `MAX_WEBHOOK_SECRET` (например, `openssl rand -hex 32`). Переменные читаются на сервере.
2. Из корня репозитория запусти `./frontend/max-bot/start.sh --dev-tunnel`. Скрипт поднимает Go-бэкенд, PostgreSQL и миграции; затем создаёт [Cloudflare Quick Tunnel](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/) без Ngrok и передаёт адрес в `WEBHOOK_BASE_URL`. Для запуска только локального API используй `./frontend/max-bot/start.sh` без аргументов.
3. Проверь `docker compose -f backend/docker-compose.yml --env-file backend/.env logs --tail=50 backend`: после регистрации появится `webhooks: max -> https://…/webhook/max`. Отправь боту `/start` в MAX.

Локальный API доступен по `http://127.0.0.1:8080` (порт можно поменять в `backend/.env`). Временный адрес сохраняется, пока работает контейнер туннеля. Чтобы выключить только туннель, выполни `docker stop studak-max-dev-tunnel`. Данные Studak сохраняются в томе PostgreSQL.

## Кого искать

При регистрации бот отдельно спрашивает, кого показывать в ленте: девушек, парней или всех. В готовой анкете это можно изменить кнопкой «Кого искать» в меню. Фильтр по вузам продолжает действовать. Для существующих анкет начальное значение — «Всех».

## Фото в анкете MAX

В конце регистрации можно отправить одно изображение из галереи MAX или пропустить шаг. В готовой анкете меню «Моя анкета» → «Фото» позволяет добавить, заменить или убрать изображение. В ленте MAX фото показывается вместе с анкетой.

Для фото из MAX в PostgreSQL хранится токен вложения, а не временная ссылка. Он не возвращается в REST API. Поэтому такое фото отображается в MAX; загрузка для сайта через это меню не настраивается. Миграция Goose применяется при запуске через Docker Compose.

## Входящие лайки и сообщения

«Кто меня лайкнул» показывает новые симпатии по одной. Можно нажать «Ответить взаимностью» или «Пропустить». Мэтчи остаются в разделе «Мои мэтчи». Если оба участника пользуются MAX, «Написать» отправляет один текст через бота. Получатель может нажать «Ответить». Личные контакты не подставляются, текст сообщений бэкенд не хранит. Сообщения с вложениями пока не поддерживаются.

## Тестовые анкеты МГУ

Из корня репозитория запусти `./backend/scripts/seed-demo-msu.sh` при работающей локальной базе Docker Compose. Команда добавит восемь вымышленных анкет МГУ с пометкой «тест». Если в базе ровно одна анкета MAX, флаг `--with-likes` добавит два входящих тестовых лайка для неё. Повторный запуск не создаёт дубли и не сбрасывает уже сделанные реакции. У тестовых анкет нет аккаунтов MAX, поэтому они подходят для проверки ленты, лайков и мэтчей, но не переписки.

## Видимость и блокировки

В главном меню кнопкой «⚙️ Настройки» можно поставить её на паузу, вернуть в поиск или удалить. Пауза скрывает анкету из поиска и откладывает новые лайки, но не закрывает переписку с существующими мэтчами. При удалении бот просит подтвердить действие; уже отправленные в MAX сообщения остаются в мессенджере.

Кнопка «Ещё» на карточке, в мэтче и в полученном сообщении открывает блокировку. После неё анкеты скрываются в обе стороны и переписка прекращается. Снять блокировку можно в настройках; старый мэтч при этом не возвращается.

## Переезд на хостинг

1. Запусти Go-бэкенд с PostgreSQL и настрой публичный HTTPS для `/webhook/max`.
2. В секретах хостинга укажи `MAX_BOT_TOKEN`, новый случайный `MAX_WEBHOOK_SECRET` и `WEBHOOK_BASE_URL=https://постоянный-домен` (без `/webhook/max`). Перезапусти бэкенд и проверь ответ на `/start`.
3. Останови временный туннель и удали его подписку через [API MAX](https://dev.max.ru/docs-api/methods/DELETE/subscriptions). Go-бэкенд заменяет подписку только для точного URL.

## Python-демо без токена

Из этой папки запусти `python3 -m iskra demo`. Тесты: `python3 -m unittest discover -s tests -v`. Этот режим использует тестовые анкеты в памяти и не подключается к Studak или MAX. Не используй токен рабочего Go-бота для запуска Python-версии.
