# Студак в Telegram

Telegram-версия находится рядом с `../max-bot`. Обе версии работают в одном Go-бэкенде, используют общие анкеты, вузы, лайки, мэтчи, блокировки и PostgreSQL.

Шаги регистрации, тексты и кнопки общие. Telegram-адаптер переводит webhook и inline-кнопки в общий сценарий. Фото обязательно для публикации анкеты. Его можно заменить новым, но нельзя пропустить при регистрации или удалить. Фото принимается одним изображением; альбомы не публикуются. У длинной анкеты Telegram показывает фото и полный текст отдельными сообщениями, чтобы не обрезать описание по ограничению подписи.

## Настройка и запуск

В `backend/.env`:

- `TG_BOT_TOKEN` — токен от верифицированного [@BotFather](https://t.me/BotFather): команда `/newbot`, название, свободное имя с окончанием `bot`.
- `TG_WEBHOOK_SECRET` — случайный секрет (например, `openssl rand -hex 32`).
- `WEBHOOK_BASE_URL` — общий HTTPS-адрес бэкенда, если запускаешь с постоянным доменом.

Секреты хранятся только в `backend/.env`, исключённом из Git. Отдельная база и копия токена в этой папке не нужны.

Из корня `studak`:

```sh
./frontend/telegram-bot/start.sh --ngrok
```

Нужны Docker, ngrok, Python 3 и curl. Авторизуй ngrok один раз командой `ngrok config add-authtoken <токен-ngrok>`.

Команда поднимает тот же сервис, что и MAX-версия. Один туннель ngrok используется для обоих webhook: `/webhook/tg` и `/webhook/max`. Скрипт получает HTTPS-адрес и передаёт его как `WEBHOOK_BASE_URL` при запуске backend; вручную менять `.env` не нужно. При заполненных токенах backend регистрирует оба webhook. Пустой токен отключает соответствующего бота. После запуска открой своего Telegram-бота и отправь `/start`.

Оставь терминал открытым. Ctrl+C остановит ngrok; backend и PostgreSQL продолжат работать. После изменения токенов в `.env` останови туннель и выполни ту же команду снова. Для Cloudflare Tunnel по-прежнему доступен флаг `--dev-tunnel`.

Проверка логов:

```sh
docker compose -f backend/docker-compose.yml --env-file backend/.env logs --tail=50 backend
```

## Что совпадает с MAX

Анкета, одно фото, поиск по вузам и полу, входящие лайки, ответ взаимностью и мэтчи с контактами для общения напрямую. Пауза, подтверждаемое удаление, блокировки и настройки нижней широкой кнопкой. Если включены оба токена, уведомления о лайках и мэтчах работают между участниками Telegram и MAX. Контакты доступны только после взаимного лайка.

Кнопки Telegram используют цветные стили: основные — синие, лайки — зелёные, удаление и блокировка — красные. Отображение зависит от поддержки стилей в клиенте Telegram.

Одинаковые числовые ID в разных мессенджерах не связывают людей: TelegramID и MaxID независимы. Автоматического объединения двух анкет одного человека нет.

Фотографии хранятся как file_id Telegram или токен MAX, скрытые из REST API. Они показываются в исходном мессенджере; для общего отображения фото между Telegram, MAX и сайтом понадобится единое медиахранилище. Публичные фото по PhotoURL поддерживаются обоими адаптерами.

## Переезд на хостинг

Разверни тот же Go-бэкенд с PostgreSQL и HTTPS, передай секреты через окружение и укажи `WEBHOOK_BASE_URL=https://постоянный-домен`. На старте он установит Telegram webhook и MAX webhook. Локальный туннель после этого останови; старую MAX-подписку нужно удалить отдельно.

## Обновлённый поиск и карточки

В регистрации доступны «Парень» и «Девушка». В справочнике есть 66 организаций
и филиалов Удмуртии, включая колледжи и техникумы. Введи название, часть названия
или сокращение: небольшие опечатки допустимы, бот предложит близкие варианты.
На карточке ❤️ означает лайк, 👎 — пропуск на два часа. Кнопка «Заблокировать»
открывает подтверждение сразу с карточки.

Лента ограничена возрастом ±2 года. Примерно 2/3 показов отдаётся приоритету:
парням — девушки младше на 1–2 года, девушкам — парни старше на 1–2 года.
Остальные показы разбавляют ленту ровесниками и другими подходящими людьми
в пределах ±2 лет. Когда одна группа заканчивается, используется другая.
Подробные правила и источники справочника — в `backend/README.md`.

## Контакты

Контакт открывается после взаимного лайка, в том числе через «Мои мэтчи».
В Telegram это `@username` и кнопка перехода, а при отсутствии username —
ссылка на профиль, если её разрешают настройки Telegram. Username обновляется
при взаимодействии пользователя с ботом; для существующей анкеты отправь `/start`.
В MAX личная ссылка добавляется вручную в «Моя анкета» → «Контакт MAX».
Старые кнопки «Написать» открывают контакт; введённый в бот текст собеседнику
не пересылается.
