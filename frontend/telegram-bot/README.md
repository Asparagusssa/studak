# Искра в Telegram

Telegram-версия находится рядом с `../max-bot`. Обе версии работают в одном Go-бэкенде, используют общие анкеты, вузы, лайки, мэтчи, блокировки и PostgreSQL.

Шаги регистрации, тексты и кнопки общие. Telegram-адаптер переводит webhook и inline-кнопки в общий сценарий. Фото принимается одним изображением; альбомы не публикуются. У длинной анкеты Telegram показывает фото и полный текст отдельными сообщениями, чтобы не обрезать описание по ограничению подписи.

## Настройка и запуск

В `backend/.env`:

- `TG_BOT_TOKEN` — токен от верифицированного [@BotFather](https://t.me/BotFather): команда `/newbot`, название, свободное имя с окончанием `bot`.
- `TG_WEBHOOK_SECRET` — случайный секрет (например, `openssl rand -hex 32`).
- `WEBHOOK_BASE_URL` — общий HTTPS-адрес бэкенда, если запускаешь с постоянным доменом.

Секреты хранятся только в `backend/.env`, исключённом из Git. Отдельная база и копия токена в этой папке не нужны.

Из корня `studak`:

```sh
./frontend/telegram-bot/start.sh --dev-tunnel
```

Команда поднимает тот же сервис, что и MAX-версия. Cloudflare Tunnel используется для обоих webhook: `/webhook/tg` и `/webhook/max`. Ngrok и polling не используются. После запуска открой своего Telegram-бота и отправь `/start`.

Проверка логов:

```sh
docker compose -f backend/docker-compose.yml --env-file backend/.env logs --tail=50 backend
```

## Что совпадает с MAX

Анкета, одно фото, поиск по вузам и полу, входящие лайки, ответ взаимностью, мэтчи и текстовая переписка через бота. Пауза, подтверждаемое удаление, блокировки и настройки нижней широкой кнопкой. Если включены оба токена, уведомления и текстовая переписка работают между участниками Telegram и MAX.

Одинаковые числовые ID в разных мессенджерах не связывают людей: TelegramID и MaxID независимы. Автоматического объединения двух анкет одного человека нет.

Фотографии хранятся как file_id Telegram или токен MAX, скрытые из REST API. Они показываются в исходном мессенджере; для общего отображения фото между Telegram, MAX и сайтом понадобится единое медиахранилище. Публичные фото по PhotoURL поддерживаются обоими адаптерами.

## Переезд на хостинг

Разверни тот же Go-бэкенд с PostgreSQL и HTTPS, передай секреты через окружение и укажи `WEBHOOK_BASE_URL=https://постоянный-домен`. На старте он установит Telegram webhook и MAX webhook. Локальный туннель после этого останови; старую MAX-подписку нужно удалить отдельно.

## Код и тесты

- `backend/internal/bots/telegrambot` — Telegram webhook, API-клиент и преобразование событий.
- `backend/internal/bots/maxbot` — общий сценарий с подключаемым транспортом; имя пакета сохранено для совместимости.
- `backend/internal/crud` — общий доступ к данным.
